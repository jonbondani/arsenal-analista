# Alcance de seguridad y publicación

Este proyecto documenta un caso de laboratorio ya público y enseña revisión de evidencias. Las utilidades incluidas trabajan con archivos locales o datos sintéticos; no se conectan al servicio vulnerable.

No añadir secretos, datos personales innecesarios, dumps privados, exploits finales o hallazgos nuevos sin un tratamiento previo adecuado. Si una revisión descubre un indicio distinto del caso público, conservarlo en privado y confirmar alcance y canal de comunicación antes de publicarlo.

No se declara un canal privado de contacto inexistente. Antes de publicar, el propietario puede habilitar un canal apropiado del repositorio. No abrir una incidencia pública que contenga material sensible.

Las futuras sesiones dinámicas requieren autorización y un entorno aislado. Una VM con red abierta puede exponer un servicio: registrar la topología efectiva forma parte de la sesión.
