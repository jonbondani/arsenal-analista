# Publicación en GitHub

[Volver al índice](../README.md)

El recurso está organizado para subir el contenido de su carpeta a un repositorio. La publicación se realiza manualmente; los archivos locales no indican si ya existe una versión pública.

## Preparar el repositorio

El nombre `el-arsenal-de-un-analista` encaja con la actividad. El README debe quedar en la raíz, junto a `ENTREGA.md`, las carpetas de documentación, las capturas y los ejemplos.

Se puede publicar como proyecto independiente y enlazar el laboratorio original. Si se integra dentro del repositorio de FreeFloat, conviene utilizar una carpeta propia y enlazarla desde su portada para conservar la documentación existente.

## Subir los archivos

1. Descomprime el ZIP y abre el README para revisar el contenido.
2. Comprueba autoría, capturas y condiciones de reutilización.
3. Crea o elige el repositorio público.
4. Sube el contenido de la carpeta manteniendo nombres y subcarpetas.
5. Evita incluir archivos de trabajo, el PDF docente o el ZIP dentro del propio recurso.
6. Revisa el resultado desde GitHub.

El [checklist](08-checklist.md) recoge las comprobaciones de privacidad, enlaces y entrega.

## Comprobar la versión pública

Abre la URL sin iniciar sesión y recorre el README, el caso práctico y el tutorial. Comprueba que se ven las seis capturas y los diagramas Mermaid y que los enlaces relativos llevan al archivo correcto.

Conserva el commit de la versión presentada y el ZIP correspondiente. Si se modifica un archivo, sus hashes también deben actualizarse para que el manifiesto siga describiendo esa versión.

## Enviar la actividad

La [memoria](../ENTREGA.md) resume el objetivo y relaciona cada requisito con su apartado. La entrega docente debe incluir la URL real del proyecto público y los datos de autoría que correspondan.

## Mantener la documentación

Las correcciones técnicas deben explicar el motivo del cambio y enlazar su evidencia. Una mejora de redacción no modifica el estado de una prueba. Si se añade una reproducción, guarda su entorno y resultados en una sesión identificada para distinguirla del material anterior.
